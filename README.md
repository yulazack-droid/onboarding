
# Mary Fisher – First 90 Days V1 Final

Clean rebuild based on the final approved UX.

## Main changes

- Overview is a working dashboard, not a landing page.
- Mission appears near the top.
- Ongoing 70% / 20% / 10% operating model appears directly under Mary's header.
- The central Overview area is **This Week**, automatically populated from the current week's key activities and incomplete carry-over items.
- Weekly 1:1 includes an agenda text box only, without a date field.
- Progress appears in four spacious categories:
  - Learning
  - Stakeholder Engagement
  - Discovery
  - Delivery
- Stakeholder Engagement is based on priority-weighted completed/recurring meetings, an explicit relationship-established checkbox, and recurring cadence.
- Each week includes Mary and Yula satisfaction ratings and a weekly reflection.
- Start date: August 11, 2026.
- Incomplete weekly activities automatically carry forward.
